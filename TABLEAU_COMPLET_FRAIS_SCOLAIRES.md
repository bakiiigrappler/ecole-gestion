## 💳 Calculs de Paiement

### **Formule de Base**
```
Total = Frais du Cycle + Frais Généraux Sélectionnés
```

### **Avec Services Mensuels**
```
Total Annuel = Total de Base + (Services Mensuels × 9 mois)

Exemple :
- Frais de base : 217,000 F (Primaire + généraux obligatoires)
- Transport : 30,000 F/mois × 9 = 270,000 F
- Cantine : 25,000 F/mois × 9 = 225,000 F
- Total : 712,000 F
```

### **Paiement Échelonné**
```
Acompte : 150,000 F (exemple)
Reste à payer : Total - Acompte
Statut : "Paiement Partiel"
```

## 🔄 Workflow dans l'Application

### **1. Création de l'Inscription**

```
Utilisateur sélectionne le niveau
         ↓
API charge les frais (cycle + généraux)
         ↓
Affichage du tableau interactif
         ↓
Utilisateur coche/décoche les optionnels
         ↓
Calcul automatique du total
         ↓
Utilisateur saisit le montant payé
         ↓
Calcul automatique du reste à payer
         ↓
Soumission du formulaire
```

### **2. Enregistrement dans la BD**

Les frais sélectionnés sont enregistrés dans :
- `enrollments` : total_fees, amount_paid, balance_due
- `enrollment_fees` : détail de chaque frais sélectionné
